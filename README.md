## ⚡ What is Prompt Compiler?

Most prompts typed into AI tools are underspecified, vague, or lack boundary constraints. **Prompt Compiler** is a Chromium extension (Manifest V3) powered by a deterministic **6-stage compilation pipeline** with optional multi-provider LLM reinforcement (**Groq**, **Google Gemini**, **OpenAI**).

It turns rough ideas into expert-tailored prompts formatted natively for **ChatGPT**, **Claude**, **Google Gemini**, **Perplexity**, and **Grok**—then injects them straight into your active chat box with **one click**.

## 🚀 Installation Guide

Prompt Compiler works out-of-the-box on all modern Chromium browsers:

## ✨ Key Capabilities

### 1. ⚡ Adaptive Compilation Depths
Avoid prompt bloat when you just need a quick query:
- `🤖 Auto`: Dynamically routes simple questions to lightweight formats and complex tasks to deep structures.
- `⚡ Light`: Direct zero-shot prompt (~40 words)—ideal for translations, quick fixes, and single-instruction tasks.
- `🎯 Standard`: Clean Markdown-structured role, mission, instructions, and output format (~180 words).
- `🛡️ Deep`: Complete 8-section expert prompt with reasoning scratchpad and self-verification.

### 2. 🎯 Model-Specific Architecture Formatting
Different models perform best with different prompt schemas:
- **ChatGPT / GPT-4o**: Formatted using clean Markdown headers (`# Role`, `# Task`) to prevent system-prompt XML tag collisions.
- **Claude (Anthropic)**: Formatted with strict XML tags (`<role>`, `<mission>`, `<rules>`), leveraging Claude’s native XML tag understanding.
- **Google Gemini**: Uses structured semantic sections tailored for Gemini’s instruction-following models.
- **Perplexity & Grok**: Lean, boundary-first instructions optimized for search synthesis and fast execution.

### 3. 🚀 1-Click Direct Chat Box Injection
No copy-pasting required:
- Prompt Compiler detects your active tab and adapts its primary action:
  - `⚡ Insert into ChatGPT`
  - `⚡ Insert into Claude`
  - `⚡ Insert into Gemini`
  - `⚡ Insert into Perplexity`
  - `⚡ Insert into Grok`
- Interacts seamlessly with modern rich-text editors (**React**, **ProseMirror**, **Lexical**, **Draft.js**, and **Quill**), auto-triggering the application's internal event buses.

### 4. 🔄 Multi-Turn Context Retention
Maintains continuous conversational context between compiler passes so follow-up queries build naturally on earlier responses without starting from scratch.

### 5. 🤖 Multi-Provider LLM Reinforcement
- **Offline Mode (Default)**: Instant ~20ms compilation running 100% locally on your machine—no API key needed.
- **Online AI Mode (Optional)**: Choose between **Groq** (`llama-3.3-70b-versatile`), **Google Gemini** (`gemini-1.5-flash`), or **OpenAI** (`gpt-4o-mini`) for automated prompt critique and self-refinement loops.
- **Session-Scoped Security**: API keys are isolated in `chrome.storage.session` and never saved in plaintext or transmitted externally.

## ⚙️ Compilation Architecture

Prompt Compiler processes your input through a modular 6-stage pipeline:

```
Raw Idea Input
   │
   ▼
[ Stage 1: Intent Extraction ] ───────► Identifies task type (87 distinct categories)
   │
   ▼
[ Stage 2: Domain Detection ] ────────► Categorizes into software, creative, data, legal, etc.
   │
   ▼
[ Stage 3: Persona Mapping ] ─────────► Matches optimal role from 100+ expert personas
   │
   ▼
[ Stage 4: Reasoning Strategy ] ──────► Sets thinking budget, step-by-step logic & validation
   │
   ▼
[ Stage 5: Structural Guardrails ] ───► Injects positive/negative constraints & output schema
   │
   ▼
[ Stage 6: Prompt Synthesis ] ────────► Assembles target-specific prompt & computes 0-24 Quality Score
```

## 🛠️ Developer Guide

Want to contribute or customize Prompt Compiler locally?

### Prerequisites
- Node.js `>= 18.0.0`
- npm

### Build Commands

```bash
# 1. Clone the repository
git clone https://github.com/rushi-gulum/prompt-compiler.git
cd prompt-compiler

# 2. Install dependencies
npm install

# 3. Build the extension (compiles to ./dist)
npm run build:ext

# 4. Generate fresh distribution package (dist.zip)
npm run package:zip

# 5. Run tests
npm test
```
